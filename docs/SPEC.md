# 出库波次交接台数据与算法

导入自备批次或复核估计时阅读。先核对下面的字段和时间窗。查看隔离行原因，再核对估计和派发结果。

## 单据

| 字段 | 用途 | 单位 | 有效区间 |
|---|---|---|---|
| `lines` | 订单行数 | 行 | 20–210 |
| `bulk_share` | 大件订单 | % | 1–58 |
| `pickers` | 可用拣货员 | 人 | 2–15 |
| `walk_m` | 平均拣货路径 | m | 40–400 |
| `merge_orders` | 需合箱订单 | 单 | 0–65 |
| `slack_min` | 距装车交接 | min | 18–125 |

`key` 是单号，`cohort` 是作业区，文本先做 NFKC 归一化。`day` 为测量工日，`received` 为到站工日，`revision` 为正整数版次。同版记录出现多个不同测量结果时隔离该单全部版次。缺测可空置，但每条单至少包含四项观测。

`outcome` 与 `result_day` 成对填写。实绩单位为分钟。 `observed` 省略时为 `true`，只在留架右截尾场景允许 `false`。

### 原始行业单据

允许使用 `form` 对象代替平铺量测。保留单号、版次、工日和标签等顶层字段。表中的换算为 `(单据值 − 原点偏移) / 倍率`。每行内部校验完成后，与平铺数据使用同一分窗、建模和派单过程。

| 单据组 | 原始字段 | 用途 | 倍率 | 原点偏移 |
|---|---|---|---:|---:|
| 批拣单 | `order_lines` | 订单行合计 | 1 | 0 |
| 批拣单 | `bulky_basis_points` | 大件占比万分数 | 100 | 0 |
| 班组签到 | `signed_workers` | 签到人头 | 1 | 0 |
| 班组签到 | `path_centimetres` | 整巷路径厘米 | 100 | 0 |
| 装车时标 | `merging_orders` | 合箱领取单 | 1 | 0 |
| 装车时标 | `truck_slack_seconds` | 交接秒数 | 60 | 0 |

示例见 `sample_data/pick_manifests_form.json`。混合使用两种量测表示，或单据内读数互相矛盾时，保留隔离原因。

## 时序与训练

拟合 `[0,40)`、校准 `[42,62)`、回放 `[65,84)`、当班从 `88` 日起。前三个窗口的入站和结果都须早于窗口终点。到站日晚于截止日的单据在入站隔离。拟合期冻结补值中位数、均值、尺度及训练包络。

| 特征 | 语义 | 公式 |
|---|---|---|
| `line_load` | 人均拣货行 | `lines / pickers` |
| `route_load` | 路径工作量 | `lines * walk_m / (100 * pickers)` |
| `bulky_load` | 大件行数 | `lines * bulk_share / 100` |
| `merge_density` | 合箱密度 | `merge_orders / lines` |
| `slack_pressure` | 交接节奏 | `lines / slack_min` |

### Huber 稳健时长回归

以绝对残差的中位数估计尺度。拟合时对超过 Huber 边界的波次降权，截距不作岭惩罚。

本工作台的独立样本校准方式为波次相对时长误差。风险校准无法确认正负样本时转人工判读。连续估计使用独立校准残差计算双侧区间，误差尺度随作业条件变化。分布监测对训练和当班量测比较Hellinger 距离。未知作业区、两项缺测或两项明显超训练包络的单据需要人工判读。

## 补派拣货班组

| 优先级 | 原因码 | 条件 | 处置依据 |
|---:|---|---|---|
| 1 | `BULKY_INTERLOCK` | `bulk_share >= 49 and pickers <= 4` | 大件通道互锁，复核叉车 |
| 2 | `HANDOFF_AT_RISK` | `estimate > slack_min - 6` | 预计逼近装车交接 |
| 3 | `MERGE_BOTTLENECK` | `merge_orders >= 48 and lines >= 110` | 合箱工位拥堵 |

第一条为暂停规则。其余命中与模型阈值 `34` 共同决定是否列入候选。单据所需工位数按 `1 + int(lines >= 110) + int(bulk_share >= 40)` 计算。均衡策略对分区限额，集中复核策略允许把额度集中投入高风险区。未分派原因在导出的处置记录中保留。签发前核对每张当班单和工位余额。

### 装车交接账

以拣货波次开始为零点，分别计拣货和合箱。只让已分派单据占用通道，按装车截止时刻倒查来不及的单。距交接还留 6 分钟缓冲，大件互锁单另行核签。 在派发环节展开现场安排，或从关联单据回查实际读数。
